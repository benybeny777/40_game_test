# 名称：はぐれものダンジョン / Dungeon Oddballs

2026-10-29、利用者から命名を委任され、表示名を「はぐれものダンジョン」、英語名を「Dungeon Oddballs」とした。紹介句は「3人編成の装備収集・放置RPG」。利用者はタイトルをいったん了承し、ゲーム品質を優先するよう指示している。今は名称検討を広げない。

採用理由は、個性的な17人と地下探索という内容が伝わり、タスクバーというWindows固有の場所に作品名を限定しないこと。マヨイモグリは内容が伝わりにくく、固有性だけでSEOに優れると判断したため撤回した。

完全一致検索で同名商品が見つからないことは、検索需要や発見性の証拠ではない。短さ・固有性だけでSEOが最良と断定しない。

比較基準：内容の伝わりやすさ（装備探索・ダンジョン・3人編成）、読みと綴りの覚えやすさ、日英の指名検索での競合、一般検索からの入口、Steam内での識別、スマホとキャラクターIP展開。公開ページ・検索実績がない現状で順位や流入を保証しない。

保存先・アプリID・クラウドgame IDは命名と分離し、変更によるセーブ消失を防ぐ。

表示名は`src/shared/brand.ts`を正本とする。Windowsの旧保存フォルダー名、実行ファイル名、ブラウザー保存キー、クラウド識別子は互換性のため維持する。商標登録・権利調査・検索順位の実績を確認したという意味ではない。
