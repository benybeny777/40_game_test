# レビュー結果：「さらにやれ、爽快感あるように」の差分

**結論：重大な欠陥は見つかりませんでした。** コア修正（前進・標的死亡時の再選択・張り手予約）はこのまま承認できます。下の3件はどれも直すべきですが、出荷を止めるほどではありません。

レビュー中に `scene.ts`・`battleNotice.ts`・`mobile/index.ts` が書き換わり、`'loot'` の通知種別が追加されました。以下は最後に読んだ時点の内容に対する指摘です。

## 指摘（優先度順）

### 1. 【中】スマホ版で、ありふれた通知が「成果」扱いのバナーになる
- **根拠：**
  - `src/renderer/mobile/index.ts:38` は、種別が `'loot'` 以外で通常技能名でもないラベルを、すべて `'good'` にしています。
  - その結果、次のものが `'good'` のバナーになります。
    - `自動売却：…` と `満杯で売却：…`（`scene.ts:262`、種別の指定なし）
    - 確変の `ハズレ`（`scene.ts:246`）
    - 連携の表示（2.4秒ごとに1回まで）
- **見え方：** `'good'` は「得た成果」として扱われます（`battleNotice.ts:3`）。そのためウェーブが切り替わっても消えず（`:43`）、表示中に来た通常技能の通知は捨てられます（`:31`）。スマホでは2.2秒表示が続きます。かばんが満杯で売却が続くと、上部の帯は売却の連絡で埋まり、「ハズレ」も祝いの扱いになります。旧通知を整理した狙いに、スマホ版だけ逆らう形です。
- **対処案：** 売却とハズレには `kind`（たとえば `'info'`）を付けて渡し、`'good'` には本当の成果だけを渡す。

### 2. 【中〜低】とどめの一撃だけ、命中時の白い点滅とヒットストップがない
- **根拠：**
  - 被弾時に `flashUntil` と `hitAt` は設定されます（`scene.ts:159-160`）。
  - しかし倒された敵は `drawUnit` の最初で描画が打ち切られます（`scene.ts:390-392`）。
  - 代わりに描かれる吹き飛びの残像は、通常のidle画像です（`scene.ts:322`、`'normal'`）。
  - 吹き飛びの動き（`defeatPose`）は減速していく形なので、最初の1フレーム目から最速で動き出します。
- **見え方：** 倒さない攻撃には点滅と一瞬の停止があるのに、いちばん気持ちよくあるべきとどめの一撃のほうが手応えが弱くなります。局所の会心エフェクトと火花は出るため、目立ちにくいのは会心ではないとどめです。
- **対処案：** 残像の最初の約45ms（`hitStopMs` 相当）は `'flash'` で、その場に止めて描く。

### 3. 【低】狙った敵が死んで別の敵に攻撃し直すと、近接の踏み込み先がずれる
- **根拠：** `finishActions` は別の敵を選び直します（`world.ts:316-317`）。一方、描画側の踏み込み先は、攻撃開始の時点で狙っていた敵の位置のままです（`scene.ts:151` と `:404`。元の標的がいなくなると `posX` が undefined になり、前の値が残ります）。
- **見え方：** 倒れた場所へ踏み込んだのに、ダメージは隣の敵に出ます。敵どうしの間隔が10ドットなので、ずれは小さめです。

## 確認して問題がなかった点
- **前進（`moveAllies`）：** 近づいてくる敵がいれば待ち、止まっている敵・遠隔の敵には近接の最短射程まで詰めます。敵を追い越すことはありません。B1で止まっていた原因の「その場から動かず撃ってくる呪いの人形」（射程200）は、これで届くようになります。
- **戦闘中だけ動くこと：** 前進は `battle` フェーズだけで行われ、`resetWave` で味方の位置が0に戻ります。出現の座標が絶対値でも、敵が味方の背後に出ることはありません。
- **張り手予約：** 移動中・攻撃の溜め中・移動速度0の敵それぞれで、待ち続けて動けなくなる条件は見当たりませんでした。ボス技の溜め（1200ms以上）の間に、張り手の再判定が間に合います。
- **カメラ：** 味方と同じ補間でカメラが動くので、味方は画面上で止まって見えます。ダメージ数字・エフェクト・小判・戦利品・残像・DOMラベルは同じ量だけずらされ、上部の帯（HUD）は動きません。ウェーブの切り替えではカメラが即座に戻り、ずれは出ません。
- **全画面フラッシュ：** 画面全体を塗る処理は戦闘の描画に残っておらず、局所の光線（6本・最大4つ）に置き換わっています。
- **監査文書：** tanks編成でB1を抜けるまでが39–45分から0.61–0.68分、最大無打撃が74–87秒から1.7–2.2秒になっており、コードの読みと合います。
