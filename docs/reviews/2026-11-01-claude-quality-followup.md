# c4776e9 製品品質の再審査（コードを読んだ範囲。実プレイは含まない）

指示どおり読み取りだけで、編集・ブラウザー操作・テスト起動はしていません。近接の接敵と衝撃演出は修正済みとして扱いました。ゲームループで具体的に残る問題を、影響が大きい順に3件挙げます。

## 1. 100階を越えると進みが2.5〜5倍遅くなるのに、装備では埋まらない（長い進行）

**根拠**
- 修羅・深淵では敵のHPが1.8倍・3倍、攻撃が1.35倍・1.8倍になります（`src/core/data/dungeon.ts:31-33`）。
- ところが装備の数値は `depthScale(options.ilvl)` で計算され、難易度の倍率が入りません（`src/core/progress/items.ts:65,75-76`）。
- 計算すると、修羅B1の敵HPは通常B99の約1.88倍です。一方、修羅B1で拾う装備は通常B99の装備より約4.5%強いだけです。修羅の中では敵と装備が同じ割合で伸びるため、この差は装備では縮まりません。
- 差を埋められるのはLvと道場ですが、Lvは60で止まり（`balance.ts:10`）、道場は効果が一定ずつなのに費用が1.5倍ずつ増えます（`profile.ts:207`）。深淵では打つ手が細くなる一方です。
- 旧版v0.7.3の240分シミュレーション（`.dev-data/sale-progress-final-2026-11-01.json`）でも、1階あたりの時間が次のように伸びています。
  - seed 27：通常B90→100は約1.9分、修羅B1→10は約4.5分、B10→20は約6.2分
  - seed 72831：約1.2分から約4.1分
  - 内容は同じ3区域で、表示はB1からやり直しです。「難しく遅くなったが新しい報酬はない」という区切りになっています。

**改善策**
- 装備の成長に難易度倍率の一部を入れて、修羅で拾った装備がそのまま答えになるようにします。
- または、修羅・深淵だけで出る新しい要素（品質段階、刻印の種類、区域など）を足し、遅くなる代わりの報酬を用意します。
- 目標は「通常B90〜100と修羅B1〜10の1階あたり時間が1.5倍以内」など、シミュレーションで測れる形で決めます。

## 2. 1〜2時間で編成が固まり、14人の控えと連携が実質使えなくなる（編成の選択）

**根拠**
- 控えに経験値は入りません（利用者が決めた仕様なので維持します）。
- 交代で入った低Lvへの補助は最大3倍で頭打ちです（`experienceSupport.ts:7`、`progress.ts:14`）。
- 旧シミュレーションの240分時点ではLv「40/40/1/40/1/…」で、控えは全員Lv1でした。
- このときLv1を入れると、目標のLv37まで約8.6万EXPが必要です。3倍の補助があっても約20分かかり、その間は深い階でLv1がすぐ倒れ、実質2人で戦うことになります。
- 武器の約3割は控え向きに出ます（`items.ts:58-59`）。しかし必要能力は階層とともに上がり（`attributes.ts:18` の `weaponPerRank 0.7`、`items.ts:89-90`）、B90の武器はLv1の控えには装備できません。控え向けの武器は、育てていない人の外れになりがちです。

**改善策**
- 経験値の補助を倍率の上限ではなく「何階で追いつくか」で決めます。たとえば数階で目標Lvに届くよう、Lv差に応じて倍率を上げます。
- 控え向けの武器は、その人がすぐ育てられるLvの必要能力で出すか、交代した直後の加入者に寄せて出します。

## 3. 敗北後の立て直しが「強くなったか」を見ず、案内も防具に偏っている（敗北後の立て直し）

**根拠**
- 3回続けて全滅すると1階戻り、2回突破すると元の階へ戻ります。このとき連続全滅の回数は0に戻ります（`game.ts:59-69`、`world.ts:367`、`progress.ts:15`）。
- 戻るかどうかの判断に、Lv・装備・道場が伸びたかが入っていません。強い壁では「3回全滅、2回突破」を繰り返し、挑戦の約6割が敗北演出になります。旧シミュレーションでも、壁の時間帯で全滅数と周回のON/OFFが増えています。
- 敗北の振り返りは、全員に「防具を比較」を出し、耐久・回復の見直しだけを勧めます（`defeatReview.ts:61,64`）。
- 記録しているのは被ダメージと致命打だけです（`defeat.ts:70-76`）。ウェーブにかかった時間や敵の残りHPがないため、深い階で増える火力不足の壁（旧シミュレーションで撃破ペースが約1/3に低下）まで防具へ誘導してしまいます。

**改善策**
- 再挑戦の条件を「前回の全滅から強さが上がった」（Lvアップ・装着・道場購入）にするか、稼ぐ回数を失敗のたびに増やします。
- 敗北記録にウェーブの時間と敵の残りHPを足し、振り返りを分けます。
  - 火力不足：武器・道場の「素振り」・攻撃役への交代へ案内
  - 耐久不足：防具・回復役へ案内
