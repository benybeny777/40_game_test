# 製品品質レビューへの対応

原文は `2026-10-29-claude-product.md`、`2026-10-29-claude-product-followup.md`、`2026-10-29-claude-product-rereview.md`。レビューは実Claude CLIによる静的確認であり、原文の試算と、その後の実コア測定・実画面確認を区別する。各提案の数値をそのまま製品仕様にしたわけではない。

| 課題 | 対応と根拠 |
|---|---|
| 最初の装備選びがない | B1初回に出撃者が使える未装着武器。比較カードで得失を見て選ぶ。20seedで序盤入手を検証 |
| 使わないジョブの武器ばかり出る | 出撃者70%／控え30%。控えの装備と育成を消さず、交代のきっかけも残す |
| 上位難度で装備が弱くなる | 通算ランク。通常・修羅の境目でも品質が巻き戻らない |
| 自動装備がトレードオフを勝手に決める | 出撃者の能力低下なしの品だけ。固有品やロック装備は自動交換しない。確定報酬は自分で比較 |
| 希少品に出会えない／見落とす | 10階初回は極以上、100階初回は伝説以上。装備不能でも極以上の新着カードと条件を表示。極振り・別ジョブ向け抽選を残すため、すべての確定品を現出撃者向けには固定しない |
| 中盤以降ほぼ無傷になる | 装備の指数成長を撤去。武器・HP・防御を別曲線へ。実ドロップでB30/50/80/100を測定。旧保存品の能力を勝手に変更しない |
| 売却ばかりが収入になる | 売値も撃破報酬と共通の成長曲線へ。修正後B100で売却収入の比率1.15〜1.47%、道場攻撃・HP各11段階 |
| ボスを見て編成を決める理由が弱い | 対象固定の予兆、詠唱中断、力士の詠唱優先。実発動条件を共有し、発動不能時の永久温存を防ぐ |
| ジョブの組合せが効かない | 注目→メイド、鈍化→スケバン、結界→番長。サムライは前方集中、メイドは対象優先投擲。速さ・安定性を別に測定 |
| 控えが育たず交代しにくい | 実出撃中の遅れた仲間だけ最大3倍の成長支援。控えへの経験値配布はしない |
| 戦闘・希少品の演出が弱い | キャラ輪郭・動作接触・会心数字・ボス予兆・伝説と神話の光柱を改善。固定イベント実画面と自然戦闘を区別 |
| 控え装備を見つけにくい | 出撃者の持ち物一覧にも使用可能な控え装備を表示し、所有者を明記。移す操作は既存equip処理へ一本化 |
| 満杯時の売却が黙って行われる | 売った実品名・小判・理由をイベント化し表示。新品が売れた場合は入手演出・音を抑止。ヘルプにも容量ルールを記載 |
| 複数tickのイベントで描画停止 | 消えたボスは正常状態として局所演出だけ省略。未知のスキルIDは例外のまま |
| エラーを成功に見せる | 原因を残して表示。main/rendererの停止境界・保存禁止・保存済み状態からの明示復帰を実装 |
| 起動直後の復帰で留守報酬が消える | 初期報酬を加えた状態を復元対象に含め、進行開始前に保存。保存失敗は停止して通知 |
| 重複・無駄な処理 | helpの日英共通描画、装備比較の共通計算、音の生成／接続／障害表示、boss発動条件、保存境界を分離 |
| スリープ復帰中の失敗で報酬や保存を壊す | オフライン計算の成功状態を保持し、表示通知前に保存。保存失敗は停止。遅れて届いたクラウド復元も異常発生後は適用しない。最終runtime再レビューで対象指摘の再現条件を解消 |
| 破損保存から無断で過去へ戻る | 原因と進行喪失の説明を伴う確認。終了時は保存ファイルを維持、復旧を選んだ場合だけ前世代を使い一時停止 |
| 端末によって明朝体になる | BIZ UDPGothicの400/700を同梱。日英の製品画面で読込・表示を確認。外部フォント配信に依存しない |
| 管理画面にも戦闘用画像をすべて展開 | sourceArtで読込を共有し、パネルは人物・敵の肖像6PNGだけ。戦闘・歩行・背景を除き、展開画像量を66→36MiBへ削減 |
