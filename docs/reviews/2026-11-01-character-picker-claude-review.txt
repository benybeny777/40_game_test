**判定：範囲を限定すれば統合できます。ただし統合前に1件（下記1）を直すことを推奨します。** ゲーム全体の販売品質を承認するものではありません。

補足：レビュー中に `index.ts` が書き換えられ、`pendingChoiceFocus` が追加されました。以下は書き換え後のコードに対する指摘で、行番号も書き換え後のものです。

### 統合前に直すべき点

**1. `pendingChoiceFocus` が消えずに残り、あとで勝手にフォーカスを奪う**（`index.ts:104`, `361-363`）
- この値は、移動先のボタンが見つかったときだけ消されます（363行）。
- 控えのカードから「交換を確定」すると、移動先は `recruit-${target.job}` になります。この時点で target は控え側に移っています。
  - 控えの役割フィルタ `reserveRole` でそのカードが除外されていると、ボタンが存在しないので値が残ります。
  - その後、フィルタを「すべて」に戻す、他のタブからパーティに戻る、背景の `onView` で再描画される、といった無関係なタイミングで、フォーカスとスクロールが突然そのボタンへ飛びます。
- 同じことは、目的のボタンが閉じた `details` の中にある場合（`focus()` が失敗したまま値だけ消える）、選択後に `swapPreview` が `null` を返して確定ボタンが描画されない場合にも起きます。
- 修正案：見つかったかどうかに関係なく、ガードを通過した描画で1回使ったら必ず消す。または `tab` を変えたときにも消す。
- 確定後の移動先は、操作していた本人の `recruit-${member.job}`（交換後は出撃側にいる）の方が自然で、確実に存在します。

### 軽微な点（統合は妨げない）

2. **交代ピッカーの選択表示が実際には出ない。** 開くときに `swapDraft = undefined`（154行）、選ぶと `swapPicker = undefined`（159行）で一覧が閉じるため、`aria-pressed=true` や ✓ が表示される状態が来ません。また、一覧を開き直すと作りかけのプレビューが消えます。「選ぶだけでは交換しない」動作は守られているので、操作が壊れているわけではありません。
3. **確定ボタンがフォーカスを受け取れない場合がある。** キーボードで選んだ瞬間に `commandPending` が真だと、確定ボタン（102行）は無効化されています。`focus()` は失敗し、値も消えるので、フォーカスは body へ落ちます。
4. **装備タブの控えピッカーが閉じたままのことがある。** 控えの仲間が `gearJob` のとき、`details.reserve-picker`（240行）は開いた状態を覚えていなければ閉じています。誰を選んでいるかは見出しでしか分かりません。
5. **意味付け（a11y）。** 1つしか選べない選択肢に `aria-pressed` ボタンを使っています。radiogroup の方が正確ですが、既存のフィルタボタンと揃っているので許容範囲です。自動売却グループの aria-label は末尾にコロンが付きます（「拾ったら自動で売る：」/「Auto sell loot:」）。

### 問題がないと確認した点
- **select の残り：** 設定タブの3つと `cloud.ts` のアカウント選択（設定タブの中）以外にはありません。`qa-scene` の select は開発用ツールなので対象外としました。CSS にも select 用の古い規則は残っていません。
- **交換の確定操作：** 選ぶと `swapDraft` が作られるだけで、`reorderParty` は「交換を確定」でしか呼ばれません。交代後の編成プレビューと確定・取り消しのボタンは残っています。
- **保存の復元：** `profileReplaced`（322行）で `swapDraft`・`swapPicker`・`pendingChoiceFocus` が破棄されます。
- **更新で選択が消えないか：** 選択状態はモジュール変数に保持され、背景更新や言語切替で再描画されても消えません。
- **フォーカスの復元：** ピッカーの各ボタン（`gear-reserve-<job>`）と自動売却ボタン（`auto-sell-<rarity>`）には固定のフォーカスキーがあります。再描画後もフォーカスが戻り、`details` の開閉状態も保たれます。
- **翻訳：** ピッカーの表示文言は日英の両方があります。index 側の新しい文言（仲間一覧を閉じる、代わりに出撃する仲間、待機中の仲間の装備、売らない、`{rarity}以下` など）はすべて translations.ts に登録されています。
- **CSS：** `.auto-sell-choices button` は、詳細度が同じでより後に書かれているため `.gear-options button` を上書きします。カードには `:focus-visible` が付いていて、高さは 44px 以上あります。
