# タスクバー百鬼行：ゲーム仕様

更新：2026-10-29。現行実装を基準に、遊び方・確定した方針・今後の案を分けて記す。実装方法は [技術仕様](TECH_SPEC.md)、最終検証の結果と未確認事項は [HANDOFF](../HANDOFF.md) を参照する。

## どんなゲームか

個性の強い17人から3人を選び、地下へ潜って装備を集める和風の放置RPG。Windowsではタスクバーの上で戦闘が進み、管理画面で編成・育成・装備を調整する。戦闘そのものは自動で、プレイヤーは「誰を出すか」「どの能力を伸ばすか」「どの装備を使うか」「先へ進むか、同じ階を周回するか」を決める。

探索の参考は初代ディアブロの地下迷宮と装備探し。現行は横向きの自動戦闘であり、自由に歩き回る見下ろし型アクションではない。暗い地下の雰囲気、階層を下りる緊張感、拾った装備で組み方が変わる楽しさを軸にする。

目標は、通常の地下100階を突破し、修羅100階を越え、最高難易度「深淵」で到達階と装備を追求すること。公開・決済を伴う外部手続きを除き、遊び・見た目・保存・配布品質まで製品として整える。

## パーティと17人

同時出撃は3人。残り14人は控えとなり、編成順の先頭3人が戦う。初期編成はサムライ・忍者・オタク。経験値は実際にその戦闘へ出撃している3人だけが受け取る。控えは経験値を得ず、現在のレベル・育成状態・装備を保持する。この変更は今後の獲得だけに適用し、以前に上がったレベルは下げない。前列は攻撃を受けやすいので、役割と並び順を組み合わせる。入れ替えと並び替えは次のウェーブから反映する。

オフライン経験値も不在時に実際に出撃していた仲間へ割り当てる。未受取報酬は対象ジョブごとの経験値を保持し、受け取り直前の編成変更で他の仲間へ振り替えない。異なる編成の期間をまとめる場合も、それぞれの対象を保持する。

タンクは敵を受け止め、アタッカーは敵を倒し、ヒーラーは回復する。バッファーは味方を強め、デバッファーは敵を弱める。

表の呼び名は現在のゲーム内ジョブ名。個人名・性格・口調・関係性の案は [キャラクター設定](CHARACTERS.md) に分けてあり、商用の公式名としての最終決定はまだ行っていない。

## ダンジョンと周回

現行のダンジョンは「黄泉の迷宮」。地下墓地・朽ちた商街・禁術の書庫という景観を巡る。

| 難易度 | 階層 | 解放 |
|---|---|---|
| 通常 | 地下1〜100階 | 最初から |
| 修羅 | 地下1〜100階 | 通常100階を突破 |
| 深淵 | 地下1階から上限を設けず進む | 修羅100階を突破 |

「無限」は最高難易度の深淵だけに適用する。通常と修羅を更新のたびに延長する方針ではない。将来のアップデートは別の雰囲気・敵・装備を持つダンジョンを加え、それぞれに進行を保存する。追加ダンジョンの内容・時期・有料か無料かは未決定。

1階につき10ウェーブ。10階ごとに大ボス、それ以外の階の最後には強敵が出る。通常の進行では階を突破すると次へ進み、通常・修羅の100階突破後は次の難易度を解放する。「周回」を選ぶと同じ階で装備と小判を稼げる。3回続けて全滅すると一つ前の階で立て直し、2回クリアすると再挑戦する。

階によって宝箱や祭壇に遭遇する。宝箱は小判・経験値・上以上の装備、祭壇は生存している味方の回復。宝箱と祭壇の報酬は進行に結び付き、同じ階への入り直しだけでは繰り返し受け取れない。

「街へ帰還」で戦闘を止めて全回復できる。育成・装備・到達記録を失わず、解放済みの階から再出発できる。全滅による装備消失はない。

### 敵の種類と読み取り方

図鑑に載る敵は12種。単なる色違いだけにせず、輪郭・動き・戦い方で区別する。

敵の画像は待機12姿の`enemy-atlas.png`と攻撃12姿の`enemy-attack.png`を使う。攻撃画像も元の敵と同じ輪郭・装飾・色の対応を保ち、待機／攻撃キーの切り替えと体の動きを組み合わせて攻撃を見せる。背景3区域は別の`dungeon-backgrounds.png`に収め、敵画像とは分けて管理する。

| 敵 | 特徴 |
|---|---|
| 提灯お化け | 揺れながら漂う近接型 |
| 河童 | 甲羅が硬く、会心にも強い装甲型 |
| 鬼火 | 浮遊して離れた位置から火を放つ |
| 大鬼 | 大きな金棒で前の二人を巻き込むボス |
| 唐傘おばけ | 一本足で跳ね、攻撃をかわす |
| 化け猫 | 素早い二連撃 |
| 招き猫もどき | 小判を多く持つ |
| 招き猫大将 | 手下を呼ぶボス |
| バグ精霊 | 飛びながら遠距離攻撃。倒すと小さい欠片二体に分裂 |
| ポップアップ鬼 | 素早く接近し、前列を巻き込んで自爆 |
| 呪いのフィギュア | 動かず後衛を狙う |
| 電脳九尾 | 狐火を放ち、体力半分で幻影を作るボス |

ボスは王冠と幅広い体力表示、最終ウェーブの強敵は菱形と橙色の体力表示で示す。色だけに依存しない。分裂片と幻影は本体より小さく、幻影は半透明にする。通常攻撃の構えには「!」と対象の足元の印を表示する。これは編成と耐久を見直すための合図で、回避操作を要求する仕組みではない。ボス特殊技の事前予告は通常攻撃とは別の今後の改善点。

図鑑は区域別に発見数・姿・主な役割・対処のヒントを示す。未発見の敵はシルエットと未発見表示にとどめる。

## 育成と能力値

最大Lv60。レベルが一つ上がるごとに3ポイントを割り振れる。

| 能力 | 主な効果 |
|---|---|
| 筋力 | 筋力を主能力にするジョブの攻撃力、防御力、重装備の条件 |
| 敏捷 | 敏捷を主能力にするジョブの攻撃力、攻撃速度・会心・回避、軽装備の条件 |
| 体力 | 最大体力と防御力、耐久装備の条件 |
| 知力 | 知力を主能力にするジョブの攻撃力、法具・法衣の条件 |

ジョブごとに初期能力と主能力が異なる。自動割り振りは主能力60%、体力20%、残る二つを10%ずつという比率を基準に、1ポイント単位で配分する。手動配分にも切り替えられる。振り直しは無料で、使ったポイントを戻して再配分できる。知力がすべての回復量を直接増やす、といった未実装の効果は付けない。

極端な筋力型・高速型・知力型・体力型も成立させる。装備条件を満たせなくなった装備は外れて所持品へ戻るため、振り直し後に条件を確認する。

道場は小判を使った共通強化。攻撃・体力・移動・装備発見・オフライン報酬時間を伸ばす。

## 装備を探す

各キャラに武器・防具・お守りの3枠。所持上限は装備中を含め100個。装備の基本性能は同種でも85〜115%の範囲で抽選され、追加効果も組み合わさる。希少度は「並・上・特上・極・伝説・神話」の6段階。神話には組み方の中心になる固有装備がある。

装備条件は**対応ジョブと能力値だけ**。キャラのレベルを直接要求しない。高い能力値を要求する装備へ向けて、自動配分を外して一点集中する選択もできる。武器はジョブとの適合、防具は種類に応じた適合と能力値を確認する。

| 神話の固有装備 | 必要な能力 | 得意な組み方と代償 |
|---|---|---|
| 巨神の断ち刃 | 筋力100・体力20、対応する筋力系武器 | 一撃の大火力。攻撃間隔は長くなる |
| 疾風の牙 | 敏捷100・体力10、対応する敏捷系武器 | 速い攻撃と会心を重ねる |
| 星詠みの聖具 | 知力100・体力20、対応する知力系武器 | スキルの待ち時間を短縮。通常攻撃は遅くなる |
| 不沈の鎧 | 体力110・筋力15 | 体力・防御と被ダメージ軽減。火力と速度を犠牲にする |

通常の敵からは確率で装備を入手し、ボスは上以上を必ず落とす。控えのジョブ用の装備も出る。自動装備、自動売却の希少度設定、個別売却、ロックを使って整理する。ロックした品は売却せず、装備中の品も直接売却できない。所持上限に達した場合は、未装備・未ロックの低い希少度の品から売却して空きを作り、保護した品しかなければ新しく拾った品を売却する。現行の装備はゲーム内専用で、Steamマーケットへ出品できる品ではない。

## 画面と操作

v0.5.1では地下墓地・朽ちた商街・禁術の書庫の3種の背景絵を追加し、階層の区域に合わせて切り替える。歩行中は壁と床を異なる速さで動かして奥行きを表現する。Windowsでは戦闘がある部分だけに背景を描き、デスクトップ全幅を覆わない。スマホの戦闘面では全幅に描く。設定の「背景と地面を表示」をOFFにすると背景と地面の帯を描かず、Windowsでは元の透過表示へ戻る。

ジョブごとに斬撃・突き・拳・掌打・投擲・術・跳躍・扇・本の動きを分ける。攻撃前の構え、踏み込み、武器の振り、戻りを強め、命中時は短い止め・閃光・反動・火花で手応えを伝える。飛び道具は投げる動作と命中の演出を分ける。これらの見た目の動きは自動戦闘の操作を変えない。

味方の通常近接攻撃は、生存している前衛の元位置を射程の基準とする。敵が前衛へ接近したときに後列の近接役も攻撃でき、表示では後列から敵の手前へ駆け込み、打撃後に元位置へ戻る。敵側の射程、遠距離攻撃、スキルの射程、内部の元位置と狙われ方、ダメージ倍率はこの修正で変えない。

現行のテンポは、階層間の歩行4秒→1.2秒、ウェーブ終了待ち1秒→0.3秒、階層クリア待ち2秒→0.8秒、通常攻撃の構え0.2秒→0.1秒へ短縮する。味方の通常攻撃間隔は初期版の0.5倍（攻撃頻度2倍）、弾速は240→360ドット/秒。敵の攻撃間隔とスキル再使用時間は維持し、能力表示の攻撃間隔も実際の間隔に合わせる。歩行中の回復率は毎秒2%→6.5%とし、1回の歩行での回復を約8%に保つ。旧版で測定した進行速度・到達階・所要時間は、この変更後の実測結果とは分けて扱う。

| 画面 | できること |
|---|---|
| 戦闘表示 | 3人の進行、攻撃・被弾・回復、階と戦闘状況を見る。キャラから管理画面を開く |
| 編成・育成 | 出撃3人と並びを変更。各キャラの能力配分・自動配分・振り直し |
| 装備 | 性能と条件を比較し、装備・ロック・売却・自動整理を設定 |
| 道場 | 小判を使った共通強化 |
| ダンジョン | 難易度・解放済み階・周回・街への帰還を選ぶ |
| 図鑑 | 発見した敵や装備を確認 |
| ストア | 外観を確認・試着。実購入が使えない環境では購入不可を表示 |
| ヘルプ・設定 | 遊び方、音や表示、停止・再開などを確認・変更 |

初回はOS／ブラウザーの言語設定を見て、日本語なら日本語、それ以外なら英語を選ぶ。手動で変更したい場合は設定画面の「言語」から選ぶ。画面上部に切替ボタンは置かない。編成・育成・装備・図鑑・ストア・ヘルプ・戦闘の案内を選んだ言語で読めるようにする。言語変更はキャラの識別や進行・装備に影響しない。

### クラウドセーブ

設定からアカウントを作成・ログインし、サーバーへセーブを保存、別端末へ復元できる。ユーザー名は半角小文字・数字・_の3〜32文字、パスワードは12〜256文字。パスワードはクライアントへ保存しない。起動をまたぐ自動ログインは未対応。

クラウドへの保存は手動。保存済みの版と更新日時を表示し、別端末で先に更新された場合は上書きを拒否する。通信結果が不明なときは再送せず、状態を確認してから操作する。復元には現在の進行を置き換える確認が必要で、復元後は一時停止する。クラウドに保存されるのはこのゲームの進行であり、設定言語・OS設定・購入権は移さない。ローカル保存に失敗したら復元成功と表示しない。

この保存は端末由来のバックアップで、取引できる装備の正当性を保証する仕組みではない。購入・装備マーケットは引き続き未接続。運用サーバーが設定されていない製品版では未接続と表示し、端末内セーブで遊べる。

ゴシック系の読みやすい書体を用い、明朝体を使わない。スマホ向けのブラウザー入口でも同じ育成と戦闘を使い、縦画面・1列カード・横に送れるナビ・押しやすいボタンを用意する。スマホ版はWindowsのタスクバー常駐機能を持たない。提供形態と確認範囲は [モバイル対応](MOBILE.md) を参照。

## 保存・放置・復帰

進行・編成・育成・装備・設定は自動保存する。アプリ終了前に特別な手動保存を要求しない。復帰時には直近の稼ぎをもとに放置報酬を計算し、まとめて受け取れる。

放置報酬は直近10分の記録を基準に、通常の稼ぎの50%。基本上限8時間、道場で最大16時間まで延長できる。装備は10分につき1回、並か上の範囲で抽選する。直近の記録がない場合は稼ぎを推測して増やさない。

壊れた保存や新しい版の保存を検出した場合、勝手な初期化で消さず、復旧または対応版が必要なことを伝える。ブラウザーの保存はその端末・ブラウザー内で独立し、Windows版やSteamの所有権と自動で共有しない。端末を替えるためのクラウド同期・保存取り込みは現時点では未提供。

Windowsで保存に失敗した場合は進行を一時停止し、保存先の空き容量や権限の確認、保存の再試行、別の場所への書き出しを案内する。復旧するまで進行を変更する操作を止め、再試行が成功しても勝手に戦闘を再開しない。終了時にも保存に失敗した場合は「ゲームへ戻る」「セーブを書き出す」「保存せず終了」を選ぶ。未保存分を失う終了は明示的に選んだ場合だけ行い、書き出し後はゲームに戻る。

ブラウザーの容量不足や別タブとの競合も停止して通知する。まず書き出してからページを読み直す。別タブの新しい進行を上書きしないため、Windowsと同じ保存の再試行は提供しない。サイトデータを削除すると保存も消えるため、端末内の書き出しを活用する。

## 販売・外観ストア

本体買い切り＋任意の外観販売を基本案とする。外観で攻撃力・経験値・小判・ドロップ率に差を付けない。現行の外観候補は桜・月・提灯・深淵の地面テーマで、30秒の試着ができる。

価格案は本体980円、外観テーマ各200円。**いずれも検討用の仮価格で、販売価格の決定・ストア登録・決済開始を意味しない。** 通常版とブラウザー版は本物の購入ができず、開発用の購入テストは実商品と分離する。
