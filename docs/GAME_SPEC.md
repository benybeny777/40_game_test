# はぐれものダンジョン：ゲーム仕様

更新：2026-11-01。現行実装を基準に、遊び方・確定した方針・今後の案を分けて記す。実装方法は [技術仕様](TECH_SPEC.md)、最終検証の結果と未確認事項は [HANDOFF](../HANDOFF.md) を参照する。

成長・装備バランスの改訂は次版候補として検証中（版番号未確定）。以下のLv100、道場返金、レアリティと補給の記述は作業中のコードを表し、v0.7.5配布物へ反映済みという意味ではない。

## どんなゲームか

個性の強い17人から3人を選び、地下へ潜って装備を集める和風の放置RPG。Windowsではタスクバーの上で戦闘が進み、管理画面で編成・育成・装備を調整する。戦闘そのものは自動で、プレイヤーは「誰を出すか」「どの能力を伸ばすか」「どの装備を使うか」「先へ進むか、同じ階を周回するか」を決める。

探索の参考は初代ディアブロの地下迷宮と装備探し。現行は横向きの自動戦闘であり、自由に歩き回る見下ろし型アクションではない。暗い地下の雰囲気、階層を下りる緊張感、拾った装備で組み方が変わる楽しさを軸にする。

目標は、通常の地下100階を突破し、修羅100階を越え、最高難易度「深淵」で到達階と装備を追求すること。公開・決済を伴う外部手続きを除き、遊び・見た目・保存・配布品質まで製品として整える。

深淵にはB100・250・500・1000、その先は1000階ごとの踏破目標がある。「深淵の遠征録」に次の目標と最高クリアを表示し、その階を実際に倒した3人のジョブ・レベル・能力配分・装備名を記録する。節目は最新8件を残す。到達しただけでは達成にせず、交代予約中の仲間も記録しない。過去版のセーブから当時の編成を推測せず、導入後の深淵クリアから記録を始める。装備を複製・復元する操作ではない。

## パーティと17人

同時出撃は3人。残り14人は控えとなり、編成順の先頭3人が戦う。初期編成はサムライ・忍者・オタク。経験値は実際にその戦闘へ出撃している3人だけが受け取る。控えは経験値を得ず、現在のレベル・育成状態・装備を保持する。この変更は今後の獲得だけに適用し、以前に上がったレベルは下げない。前列は攻撃を受けやすいので、役割と並び順を組み合わせる。入れ替えと並び替えは次のウェーブから反映する。

オフライン経験値も不在時に実際に出撃していた仲間へ割り当てる。未受取報酬は対象ジョブごとの経験値を保持し、受け取り直前の編成変更で他の仲間へ振り替えない。異なる編成の期間をまとめる場合も、それぞれの対象を保持する。

途中から参加した低レベルの仲間には、出撃中の最高レベルとの差が3を超える間だけ戦闘経験値の育成支援が付く。倍率は差に応じて増え最大3倍、先輩の3レベル下まで追いつくと終了する。控え・交代予約中の仲間へ経験値を配らず、控えの最高レベルも参照しない。オフライン報酬にはこの補正を適用しない。

タンクは敵を受け止め、アタッカーは敵を倒し、ヒーラーは回復する。バッファーは味方を強め、デバッファーは敵を弱める。

## ダンジョンと周回

ボス予告では対策と初回突破の報酬を一緒に見せる。10階ごとの初回は特上以上、100階ごとの初回は極以上の装備1品。獲得済みの階へ戻る場合は初回報酬を再び約束しない。通常・修羅の100階では次難度の解放も案内する。持ち物が満杯なら、新報酬も整理売却される可能性があることを事前に表示する。

編成画面は攻撃役と仲間を回復する手段を短く表示し、技能・守りの詳細は開いて確認する。交換前後で変わる特徴を示す。オタクの回復も数え、キョンシーの自己復活は仲間の回復とは区別する。装備条件が足りない場合は、その装備を目標として対象キャラのステ振りへ移り、不足値を確認して比較へ戻れる。操作なしに振り直したり、装備したりしない。

敗北の詳細には、観測できた戦闘時間と敗北時に生き残った敵の数・残HP割合を残す。残HPは生き残った敵だけの合計最大HPに対する割合で、波全体を削った割合ではない。古い記録や開始を観測していない時間は「記録なし」。火力不足と決めつけず、武器・防具の双方を比較できる。

近接の仲間は、離れた場所で止まっている敵へ隊列ごと近づいて攻撃する。こちらへ接近してくる敵は迎え撃ち、前衛・後衛の並びは維持する。振りかぶっている間に狙った敵が倒れた場合は、届く範囲の別の敵へ攻撃をつなぐ。攻撃力やゲーム速度を上乗せせず、攻撃できずに待つ時間を取り除く。

敵撃破には短い吹き飛びと消滅、会心には当たった場所の衝撃線を付ける。一閃も画面全体を白くせず、斬撃部分を強調する。通常技能名の連続表示は間隔を空け、ボスの予兆・連携・希少装備の発見を優先する。獲得した装備の通知は次のウェーブへ進んでも読める時間を確保する。

編成画面では実際に出撃している3人の専用連携を示す。ギャルの注目とメイドのナイフ、巫女の結界と番長の反撃、ガリ勉の攻撃間隔増加とスケバンの追撃を対象に、技能の必要レベルと状態条件を表示する。揃えただけで常時発動するとは扱わず、専用連携のない編成も役割や装備で選べる。交換候補は役割・レベル付きで選び、交換後の3人、失う連携、出撃した場合の育成支援上限を確認してから確定する。取り消した場合は編成を変えない。控えへ育成経験値を配る仕組みではない。

現行のダンジョンは「黄泉の迷宮」。地下墓地・朽ちた商街・禁術の書庫という景観を巡る。

| 難易度 | 階層 | 解放 |
|---|---|---|
| 通常 | 地下1〜100階 | 最初から |
| 修羅 | 地下1〜100階 | 通常100階を突破 |
| 深淵 | 地下1階から上限を設けず進む | 修羅100階を突破 |

「無限」は最高難易度の深淵だけに適用する。通常と修羅を更新のたびに延長する方針ではない。将来のアップデートは別の雰囲気・敵・装備を持つダンジョンを加え、それぞれに進行を保存する。追加ダンジョンの内容・時期・有料か無料かは未決定。

1階につき10ウェーブ。10階ごとに大ボス、それ以外の階の最後には強敵が出る。通常の進行では階を突破すると次へ進み、通常・修羅の100階突破後は次の難易度を解放する。「周回」を選ぶと同じ階で装備と小判を稼げる。3回続けて全滅すると一つ前の階で立て直し、最初は2回クリアして再挑戦する。同じ壁への再挑戦でまた敗れたら育成周回を4回、8回（上限）へ増やす。迷宮画面に周回数を示し、編成・装備を整えたら待たずに再挑戦を予約できる。壁突破、街帰還、手動移動・周回変更で自動立て直しを解除する。B1は戻る階がないため、突破したら通常どおりB2へ進む。

階によって宝箱や祭壇に遭遇する。宝箱は小判・経験値・上以上の装備、祭壇は生存している味方の回復。宝箱と祭壇の報酬は進行に結び付き、同じ階への入り直しだけでは繰り返し受け取れない。

「街へ帰還」で戦闘を止めて全回復できる。育成・装備・到達記録を失わず、解放済みの階から再出発できる。全滅による装備消失はない。

区域によって狙いやすい装備が変わる。地下墓地は防具、朽ちた商街は武器、禁術の書庫はお守りの抽選重みが2倍になる。「出現確率が2倍」や確定報酬ではなく、どの区域でも他の種類は出る。神話固有装備や種類を指定した報酬は対象外。新しく抽選する装備に適用し、所持済み装備の種類・性能は書き換えない。迷宮画面に現在区域と各区域の傾向、近い到達済み階への移動を日英で表示する。候補には現在階との差を表示する。浅い階は戦いやすい一方、同じ希少度の装備なら基礎性能が低くなる傾向があり、抽選値の幅も残る。探索中の現在地と同じ予約先は再送せず、同じ階に留まりたいときは周回をONにする。

階層入力は、入力欄から出発ボタンへ移ったり画面の数値が更新されたりしても保持する。難度を変えると入力先を切り替え、ゲームの保存データには未送信入力を含めない。移動が受理されたら未送信入力を消し、失敗時は入力を残す。戦闘中に階層や難度を変えた場合は「移動予約」と行き先を表示し、次のウェーブから移動する。街・歩行中はすぐに移動を開始する。

全滅時は、そのウェーブで実際に戦った3人のレベル・被ダメージ・倒れた順・記録できた致命打を直近1件だけ残す。同時に倒れた仲間は同順位とし、回復・蘇生を挟んだ被ダメージは最大HPを超えることがある。記録から編成見直し、防具比較、同じ階への再挑戦へ進める。旧セーブに敗北情報がなければ記録なしとし、過去の敗北を作らない。該当階の突破実績が確認できる記録は「突破実績あり」として折り畳む。敗北後に突破したという時系列は保証しない。記録と操作は日英で表示する。

### 敵の種類と読み取り方

パーティと迷宮画面には、この先に現れる大ボスの階・名前・対処のヒントを共通表示する。対象は実際の区域と10階刻みの出現定義から求め、現在いる階が大ボス階ならそのボスを示す。移動予約中は予約先の経路へ切り替える。対策の役割候補は折り畳み、特定の編成を必須とはしない。

図鑑に載る敵は12種。単なる色違いだけにせず、輪郭・動き・戦い方で区別する。

敵の画像は待機12姿の`enemy-atlas.png`と攻撃12姿の`enemy-attack.png`を使う。攻撃画像も元の敵と同じ輪郭・装飾・色の対応を保ち、待機／攻撃キーの切り替えと体の動きを組み合わせて攻撃を見せる。背景3区域は別の`dungeon-backgrounds.png`に収め、敵画像とは分けて管理する。

|---|---|
| 提灯お化け | 揺れながら漂う近接型 |
| 河童 | 甲羅が硬く、会心にも強い装甲型 |
| 鬼火 | 浮遊して離れた位置から火を放つ |
| 大鬼 | 大きな金棒で前の二人を巻き込むボス |
| 唐傘おばけ | 一本足で跳ね、攻撃をかわす |
| 化け猫 | 素早い二連撃 |
| 招き猫もどき | 小判を多く持つ |
| 招き猫大将 | 手下を呼ぶボス |
| 書喰いの蟲 | 飛びながら遠距離攻撃。倒すと小さい欠片二体に分裂 |
| 呪いの映し箱 | 素早く接近し、前列を巻き込んで自爆 |
| 呪いの人形 | 動かず後衛を狙う |
| 禁書の九尾 | 狐火を放ち、体力半分で幻影を作るボス |

ボスは通算50階から初期技と変化技を30階単位で巡回し、難度ごとに型をずらす。同じ主との再戦でも、集中攻撃・広域攻撃・後衛狙い・混成召喚への備えを見直せる。変化技は大鬼が前3人×1.4（初期は前2人×2）、九尾が後2人×1.8（初期は3人×1.2）。招き猫大将の混成召喚は招き猫もどき1体と化け猫1体で、攻撃間隔と二連撃を含む防御適用前の基礎DPSを初期2体分に揃える。各100階の山場ではHP半分を境に初期技から変化技へ移行する。予告中の技と対象は変えず、次回の技から移行する。次ボスカードと図鑑にも同じ型・山場の変化を表示する。

ボスは王冠と幅広い体力表示、最終ウェーブの強敵は菱形と橙色の体力表示で示す。色だけに依存しない。分裂片と幻影は本体より小さく、幻影は半透明にする。通常攻撃の構えには「!」と対象の足元の印を表示する。ボス特殊技は技名・残り時間・対象の印で予告し、予告開始時に対象を確定する。標準速度での実時間は大鬼0.6秒、招き猫大将0.9秒、九尾0.7秒。予告中に倒す、または力士が十分に押し戻すと中断し、技は再使用待ちに入る。これは編成と耐久を見直すための合図で、回避操作を要求する仕組みではない。

力士の張り手は、届く範囲で予告中のボスを近くの護衛より優先する。ボスが実際に技を出せる状態で次の技が間近なら短く温存し、予告を押し戻して止める。召喚した手下が上限に達しているなど、ボスが発動できない間は張り手を温存し続けない。射程外の敵には届かず、張り手の再使用待ちもあるため、すべての大技を止められるわけではない。

図鑑は区域別に発見数・姿・主な役割・対処のヒントを示す。未発見の敵はシルエットと未発見表示にとどめる。

## 育成と能力値

最大Lv100。レベルが一つ上がるごとに3ポイントを割り振れる。旧版のLv60・経験値・配分は保持し、Lv1へ戻さない。必要経験値はLv10まで従来の曲線を維持し、それ以降は段階的に重くなり、Lv60以降はさらに長期の成長になる。上限では次レベル経験値を表示せず、装備探しと配分の見直しを案内する。

レベルと属性配分の主な役割は装備条件を満たすこと。属性による攻撃・耐久・速度などの直接効果は逓減し、レベルだけで弱い初期装備を使い続けて突破できる設計にはしない。良い追加効果・刻印・固有効果が編成に合う装備は、少し深く進んだだけで陳腐化しないよう調整する。

| 能力 | 主な効果 |
|---|---|
| 筋力 | 筋力を主能力にするジョブの攻撃力、防御力、重装備の条件 |
| 敏捷 | 敏捷を主能力にするジョブの攻撃力、攻撃速度・会心・回避、軽装備の条件 |
| 体力 | 最大体力と防御力、耐久装備の条件 |
| 知力 | 知力を主能力にするジョブの攻撃力、法具・法衣の条件 |

ジョブごとに初期能力と主能力が異なる。自動割り振りは主能力60%、体力20%、残る二つを10%ずつという比率を基準に、1ポイント単位で配分する。手動配分にも切り替えられる。振り直しは無料で、使ったポイントを戻して再配分できる。知力がすべての回復量を直接増やす、といった未実装の効果は付けない。

極端な筋力型・高速型・知力型・体力型も成立させる。装備条件を満たせなくなった装備は外れて所持品へ戻るため、振り直し後に条件を確認する。

道場は小判を使い、移動・装備発見・オフライン報酬時間を伸ばす。攻撃・最大HPの強化は廃止する。旧セーブの購入段数から当時の累積費用を計算し、所持できる空き分を小判へ返金する。上限で受け取れない残額も保存し、道場に返金済み額と残額を表示する。小判を使った後は「返金を受け取る」で残額を引き出せる。旧強化段数はゼロにし、返金記録を保存して再読込による二重返金を防ぐ。金額の不整合はエラーとし、合法な高額購入歴を上限超過だけで拒否したり残額を切り捨てたりしない。

## 装備を探す

各キャラに武器・防具・お守りの3枠。所持上限は装備中を含め100個。装備の基本性能は同種でも85〜115%の範囲で抽選され、追加効果も組み合わさる。希少度は「並・上・特上・極・伝説・神話」の6段階。神話には組み方の中心になる固有装備がある。

次版候補の通常抽選用レアリティ倍率は順に1 / 1.2 / 1.8 / 2.8 / 4.5 / 4。基礎性能に使う。追加効果の抽選倍率は別に1 / 1.1 / 1.25 / 1.45 / 1.7 / 2を使い、神話には別途固有効果・代償もあるため、色だけで強弱を断定しない。装備条件はレアリティ倍率から増やさず、種類・ジョブ・装備ランクに基づく属性条件、または固有装備の専用条件を使う。旧版で抽選済みの性能・追加効果・保存済み条件は再抽選しない。

装備条件は**対応ジョブと能力値だけ**。キャラのレベルを直接要求しない。高い能力値を要求する装備へ向けて、自動配分を外して一点集中する選択もできる。武器はジョブとの適合、防具は種類に応じた適合と能力値を確認する。

| 神話の固有装備 | 必要な能力 | 得意な組み方と代償 |
|---|---|---|
| 巨神の断ち刃 | 筋力100・体力20、対応する筋力系武器 | 一撃の大火力。攻撃間隔は長くなる |
| 疾風の牙 | 敏捷100・体力10、対応する敏捷系武器 | 速い攻撃と会心を重ねる |
| 星詠みの聖具 | 知力100・体力20、対応する知力系武器 | スキルの待ち時間を短縮。通常攻撃は遅くなる |
| 不沈の鎧 | 体力110・筋力15 | 体力・防御と被ダメージ軽減。火力と速度を犠牲にする |

通常の敵からは確率で装備を入手し、ボスは特上以上を必ず落とす。控えのジョブ用の装備も出る。自動装備、自動売却の希少度設定、個別売却、ロックを使って整理する。ロックした品は売却せず、装備中の品も直接売却できない。所持上限に達した場合は、未装備・未ロックの低い希少度の品から売却して空きを作り、保護した品しかなければ新しく拾った品を売却する。現行の装備はゲーム内専用で、Steamマーケットへ出品できる品ではない。

### 拾って選ぶ流れ

新着案内は、出撃中の仲間が今使える改善品・技能特性を変える品を優先する。「保留して次を見る」はその一品の新着表示だけを外し、持ち物・ロック・所有権を変えない。比較後の装着は自分で選べる。

新しく拾う装備名はランク1・6・16・31・61・101・141・181で変わる8段階。武器は17ジョブ別、防具は重装・軽装・法衣で異なる。改の表記はランク201以降、25ランクごと。過去の保存品を勝手に改名しない。

極・伝説の武器には20%で「技能刻印」が付く。集中は通常スキルの攻撃力を参照する部分が1.5倍、持続は通常スキルの効果時間が1.5倍になる。どちらも通常スキルの再使用までの時間が1.3倍になる代償がある。適合する技能を持つジョブだけに抽選し、奥義・パッシブ・通常攻撃を直接強化しない。神話固有品には付かない。

刻印の種類が変わるときは単純な強弱ではないため、総合評価の▲▼を出さず「技能特性が変わる」と表示し、今の効果・新しい効果・代償を比較する。同じ刻印同士なら通常の評価差を表示する。個別の攻撃・防御などの数値差は確認できる。刻印品を自動装備したり、装備中の刻印品を自動で外したりしない。

通常1階の初回突破で、出撃者がその場で使える上の武器を比較用に入手する。10階ごとの初回突破は特上以上、100階ごとの初回突破は極以上を保証し、これらは通常の自動装備・希少度指定の自動売却に回さない。ただし持ち物満杯時の整理売却は適用される。同じ階の再クリアで初回報酬を増やすことはできない。武器の通常抽選は出撃者70%、控え30%を基本とする。

それ以外の非ボス階突破では、出撃者の武器・防具の空き枠を優先し、空きがなければ現在階・同ジョブ・同枠の並品（基礎抽選100%）を基準に実効基礎値の比が最も低い枠へ向けて並または上の装備1個を補給する。同じ階の再周回でも補給する。武器は攻撃、防具はHPと防御の比の平均で選び、追加効果・刻印・固有効果の相性は評価しないため、現品より強いことや、その場で装備条件を満たすことは保証しない。通常の自動装備・売却設定と所持上限を適用する。

装備ランクは階層＋難易度×100で連続し、修羅・深淵に入っても1へ戻らない。新しく拾う武器と防具は敵と共通の進行座標を使い、通算ランク200までの区間成長と、その先の緩やかな成長を分ける。防具の体力と防御力を同じ勢いで膨らませず、深い階でも防御・回復・編成の選択が役立つようにする。装着条件は引き続きジョブと能力値のみ。

装備名の「改」は深層でも増え続け、「改玖」の先は「改10」「改11」…と表示する。更新前に入手済みの品は、保存された名前・基本性能・抽選した追加効果をそのまま保持する。戦闘と比較では共通の実効値を使い、旧生成品には新旧の希少度倍率の比を補正する。保存品の再抽選はしないため、旧版の強力な品と新規入手品には性能差が残る。

売却価格は階層の撃破報酬と同じ緩やかな伸びに希少度を掛けて決める。並ならランク30で22小判、60で40小判、100で64小判。深層の不要品だけが巨額になる状態を避け、敵からの小判やパチプロ・ホームレスの獲得ボーナスにも価値を残す。保存済みの品も、売却時には現行の共通価格計算を使う。品の戦闘性能は変えない。

自動装備は出撃者だけを対象に、能力を一つも下げない改善を選ぶ。固有装備を自動採用せず、使用中の固有・ロック装備を自動交換しない。手動比較には装着前後の攻撃・耐久・速度・追加効果の増減を示す。評価差は目安であり、上がるだけで最適と断定しない。新着表示は閲覧時間で勝手に消さず、装着・売却・確認済み操作で整理する。

## 画面と操作

v0.5.1では地下墓地・朽ちた商街・禁術の書庫の3種の背景絵を追加し、階層の区域に合わせて切り替える。歩行中は壁と床を異なる速さで動かして奥行きを表現する。Windowsでは戦闘がある部分だけに背景を描き、デスクトップ全幅を覆わない。スマホの戦闘面では全幅に描く。設定の「背景と地面を表示」をOFFにすると背景と地面の帯を描かず、Windowsでは元の透過表示へ戻る。

ジョブごとに斬撃・突き・拳・掌打・投擲・術・跳躍・扇・本の動きを分ける。攻撃前の構え、踏み込み、武器の振り、戻りを強め、命中時は短い止め・閃光・反動・火花で手応えを伝える。飛び道具は投げる動作と命中の演出を分ける。これらの見た目の動きは自動戦闘の操作を変えない。

味方の通常近接攻撃は、生存している前衛の元位置を射程の基準とする。敵が前衛へ接近したときに後列の近接役も攻撃でき、表示では後列から敵の手前へ駆け込み、打撃後に元位置へ戻る。敵側の射程、遠距離攻撃、スキルの射程、内部の元位置と狙われ方、ダメージ倍率はこの修正で変えない。

標準速度は全体2倍を維持し、追加調整で歩行の見た目と移動待ちをさらに速める。道場の移動補正がない場合、階層間の歩行は実時間0.3秒（前版0.6秒）。歩く足と背景の移動速度も前版の2倍に揃える。戦闘中の攻撃間隔・スキル再使用時間はこの追加調整では変えず、ウェーブ終了待ち0.15秒、階層クリア待ち0.4秒、通常攻撃の構え0.05秒を維持する。前回調整の味方通常攻撃間隔0.5倍、弾速360ドット/秒はゲーム内時間での設定値。歩行の回復量は短縮前の1.2秒分を予算として保持し、道場補正なしでは1回約8%回復する。道場による移動時間短縮と刻みの丸めを含む従来の回復量も維持する。プレイ時間・放置報酬の経過時間・説明や設定操作の時間は実時間のままとする。旧版の進行速度・到達階・所要時間は現行の実測結果と区別する。

初回はOS／ブラウザーの言語設定を見て、日本語なら日本語、それ以外なら英語を選ぶ。手動で変更したい場合は設定画面の「言語」から選ぶ。画面上部に切替ボタンは置かない。編成・育成・装備・図鑑・ストア・ヘルプ・戦闘の案内を選んだ言語で読めるようにする。言語変更はキャラの識別や進行・装備に影響しない。

### クラウドセーブ

設定からアカウントを作成・ログインし、サーバーへセーブを保存、別端末へ復元できる。ユーザー名は半角小文字・数字・_の3〜32文字、パスワードは12〜256文字。パスワードはクライアントへ保存しない。起動をまたぐ自動ログインは未対応。

クラウドへの保存は手動。保存済みの版と更新日時を表示し、別端末で先に更新された場合は上書きを拒否する。通信結果が不明なときは再送せず、状態を確認してから操作する。復元には現在の進行を置き換える確認が必要で、復元後は一時停止する。クラウドに保存されるのはこのゲームの進行であり、設定言語・OS設定・購入権は移さない。ローカル保存に失敗したら復元成功と表示しない。

この保存は端末由来のバックアップで、取引できる装備の正当性を保証する仕組みではない。購入・装備マーケットは引き続き未接続。運用サーバーが設定されていない製品版では未接続と表示し、端末内セーブで遊べる。

ゴシック系の読みやすい書体を用い、明朝体を使わない。スマホ向けのブラウザー入口でも同じ育成と戦闘を使い、縦画面・1列カード・横に送れるナビ・押しやすいボタンを用意する。スマホ版はWindowsのタスクバー常駐機能を持たない。提供形態と確認範囲は [モバイル対応](MOBILE.md) を参照。

通知音は初期OFF。伝説・神話の発見、大ボス突破、10レベルごとの成長だけ短い音で知らせる。音量調整可能、通知間隔10秒以上・1時間最大10回。非表示・停止中は鳴らさない。音の失敗は保存の失敗と分けて表示し、設定OFF→ONで明示的に再試行する。

## 保存・放置・復帰

進行・編成・育成・装備・設定は自動保存する。アプリ終了前に特別な手動保存を要求しない。復帰時には直近の稼ぎをもとに放置報酬を計算し、まとめて受け取れる。

毎分収入の途中経過も保存する。短時間で再起動や復元を繰り返しても、途中の稼ぎが次の1分へ余分に加わらない。旧版で時間を記録していなかった途中の集計は、時間不明の履歴としてセーブ内に保持し、新しい毎分収入には混ぜない。すでに得た所持金・経験値と、確定済みの毎分記録は失わない。

街で休息している時間も毎分率の計測には含み、収入0の時間として平均へ反映する。探索プレイ時間は街では増えない。街から再出発した直後は平均収入が低くなる場合があり、直近の探索実績で更新される。

放置報酬は直近10分の記録を基準に、通常の稼ぎの50%。基本上限8時間、道場で最大16時間まで延長できる。装備は10分につき1回、並か上の範囲で抽選する。直近の記録がない場合は稼ぎを推測して増やさない。街で休息中はオフライン報酬を得ない。

壊れた保存や新しい版の保存を検出した場合、勝手な初期化で消さず、復旧または対応版が必要なことを伝える。ブラウザーの保存はその端末・ブラウザー内で独立し、Windows版やSteamの所有権と自動で共有しない。接続先を設定した環境では、上記の手動クラウドセーブで進行を移せる。

Windowsで前回の保存だけが読み込めた場合も、黙ってそこへ戻さない。読み込み時の原因と、前回の保存以降の進行が失われることを説明し、「前回の保存から復旧」を選んだ場合だけ一時停止で開く。既定の選択とキャンセルは終了で、通常の保存と前回の保存を上書きしない。

Windowsで保存に失敗した場合は進行を一時停止し、保存先の空き容量や権限の確認、保存の再試行、別の場所への書き出しを案内する。復旧するまで進行を変更する操作を止め、再試行が成功しても勝手に戦闘を再開しない。終了時にも保存に失敗した場合は「ゲームへ戻る」「セーブを書き出す」「保存せず終了」を選ぶ。未保存分を失う終了は明示的に選んだ場合だけ行い、書き出し後はゲームに戻る。

ブラウザーの容量不足や別タブとの競合も停止して通知する。まず書き出してからページを読み直す。別タブの新しい進行を上書きしないため、Windowsと同じ保存の再試行は提供しない。サイトデータを削除すると保存も消えるため、端末内の書き出しを活用する。

### 書き出したセーブを戻す

Windows版・ブラウザー版とも、設定の「セーブファイルの取り込み」から、書き出したJSONを選んで進行を復元できる。ファイルは1MiB以下。保存日時、難易度と階、小判、プレイ時間、出撃3人のレベルを確認してから「現在の進行を置き換えて復元」を押す。確認中に進んだ分も含め、現在の進行を選んだファイルで置き換えるため、残したい場合はキャンセルして先に書き出す。選択・内容確認・キャンセルだけでは現在の保存を変更しない。

正常起動中の取り込みは設定と購入した外観を変えず、成功後は一時停止する。保存時刻からファイルの内容確認を開いた時点までのオフライン報酬を通常の上限・対象者ルールで計算し、受取待ちへ加える。確認画面を開いた後に待った時間は追加しない。不正なJSON、不適切な数値、対応できない未来版、容量超過、保存先の障害や別タブ更新がある場合は原因を表示し、復元成功と扱わない。

ブラウザーの保存が壊れてゲームを開けない場合も、起動エラー画面から書き出し済みファイルを選べる。この経路では、設定もOS／ブラウザーの言語に合わせた初期設定へ置き換えることを確認画面で説明し、明示確認後だけ保存して一時停止で読み直す。既存データが未来版の場合は、この復旧でも上書きせず対応版を案内する。保存領域へアクセスできない状態では取り込みで回避せず、ブラウザー側の問題を解消する必要がある。

## 販売・外観ストア

購入サービスへ接続していない環境では、ゲーム内の入口を「外観」、画面を「外観プレビュー」と表示する。30秒の試着と取得済み外観の適用は使えるが、価格予定・購入できないボタン・Steam取引の準備中広告は出さない。以下の販売案は開発資料として保持し、ゲーム内で提供済みと誤認させない。

本体買い切り＋任意の外観販売を基本案とする。外観で攻撃力・経験値・小判・ドロップ率に差を付けない。現行の外観候補は桜・月・提灯・深淵の地面テーマで、30秒の試着ができる。

価格案は本体980円、外観テーマ各200円。**いずれも検討用の仮価格で、販売価格の決定・ストア登録・決済開始を意味しない。** 通常版とブラウザー版は本物の購入ができず、開発用の購入テストは実商品と分離する。

Steam販売・外観購入・将来のマーケットは別々の実装と手続きを要する。現段階でSteam取引や実課金を開始したとは扱わない。取引の設計と未実装範囲は [販売設計](COMMERCE.md)、出荷の条件は [配布手順](RELEASE.md) を参照。

## 絵とキャラクターの完成条件

少ない色数、角の見えるドット、縮小しても判別できる輪郭を揃える。光沢の強い細密な絵を単に縮める仕上げを避け、17人を並べたときの線・影・顔・大きさ・動作を統一する。農民の弱々しさ、老人の汚れと箱一つ、メイドとシスターの服の違いは明示的な採用条件。

現行素材はAIを使って制作したもの。手描きと偽って説明しない。生成原本、参照、修正、採否、最終監修を記録し、画面での識別性と独自性を確認する。人名・設定・画風の商用最終承認や名称調査は未完であり、既存作品の人物をそのまま商品化する方針ではない。詳細は [IP制作管理](IP.md) と [キャラクター設定](CHARACTERS.md) を参照する。

最終のプレイ・画面・配布検証と残課題は [HANDOFF](../HANDOFF.md) を正本とする。本書の記載だけで全環境の動作確認完了を示さない。

### キャラカードによる選択

編成の「仲間を交代」から顔・名前・Lv・役割・出撃状態の一覧を開く。候補を選ぶと交代前後の2人と編成の変化を確認し、確定するまで出撃メンバーは変わらない。待機中の仲間からも同じ方法で交代できる。装備画面も顔付き一覧から仲間を選び、選択後は一覧を閉じて対象の装備へ移る。プルダウンは設定画面だけに用いる。
