# ブラウザー・スマホ向けの共通実装

Windowsの常駐版と同じ`src/core/`を、ブラウザー上で動かす入口を`src/renderer/mobile/`へ追加した。管理パネル・戦闘Scene・キャラクター素材も共有し、スマホ用CSSでタッチ操作と縦画面へ合わせる。ネイティブのタスクバー常駐やSteam決済をブラウザーへ持ち込まない。

## 入口と接続

- `src/renderer/platform.ts`の`initializePlatform()`が、既存の`window.game`を見つけた場合はそのまま利用する。Electron preloadのAPIを置換しない。
- ブラウザーでは同じ`ShellApi`契約を実装し、pure coreの`createGame`・`advance`・`runCommand`・`snapshot`・`buildView`を呼ぶ。進行速度は10Hzで、rendererのフレーム間隔と分ける。
- mobile entryはadapterの初期化後に共通panelをdynamic importする。画像の読込が終わってからSceneで3人の戦闘を描く。
- 独立した`vite.web.config.ts`はmobileだけを入口にし、`dist/web/`へ相対URLで出力する。Electron main/preloadやWindows専用モジュールをブラウザーへ含めない。

## 起動とWebビルド

開発中はプロジェクトのルートから次を実行する。

```powershell
pnpm web:dev
```

PCで`http://127.0.0.1:5174/mobile/`を開く。スマホから同じネットワーク内のPCへ接続する場合は`pnpm web:dev --host 0.0.0.0`とし、`http://<PCのLANアドレス>:5174/mobile/`を開く。利用するネットワークでPCへの接続が許可されている必要がある。開発サーバーをインターネットへ公開しない。

配信用のファイルを生成して確認する場合は次を実行する。

```powershell
pnpm web:build
pnpm web:preview
```

PCで`http://127.0.0.1:4174/`を開くとmobile入口へ移る。スマホ確認は`pnpm web:preview --host 0.0.0.0`とし、同じネットワークから`http://<PCのLANアドレス>:4174/`を開く。previewはビルド済みファイルの確認用で、変更後は再度`web:build`が必要。終了はCtrl+C。

生成物の`dist/web/`一式はHTTPサーバーで配信する。HTMLファイルのダブルクリック、PCのローカルパスの共有だけでは起動できない。公開HTTPS配信先へのアップロードは実施しない。相対URLで素材を参照するため、サブディレクトリー配信にも対応するが、実際の配置先で画面・保存オリジンを確認する。ビルド先にも短い`README.txt`を含める。設定とコアの関係は[技術仕様](TECH_SPEC.md)、遊びの内容は[ゲーム仕様](GAME_SPEC.md)を参照。

## セーブ

保存先はブラウザーの`localStorage`にある`hyakkiko.web.save`だけ。`{format, profile, settings, state}`を1回の`setItem`で保存するため、プロフィールと一時停止設定の部分更新を避ける。Windowsの開発用データ・AppData・Steam所有権・有料商品の権利とは独立している。ブラウザー／プロファイル／サイトのオリジンが違えば別セーブになる。

- 旧版プロフィールの移行は共通coreを使う。未来版・破損・読取不能の保存データは上書きせず、エラー画面で停止する。
- 容量不足や書込失敗時は一時停止して通知する。初期化や自動削除はしない。別タブが同じセーブを書き換えた場合も停止し、古い状態による上書きを防ぐ。
- 5秒ごと、コマンド、階層突破、バックグラウンドへ移るときに保存する。背景で無制限にシミュレーションを回さない。戻った時点までの時間は既存のオフライン報酬へ置き換え、受取待ち報酬と新しい時刻を同時に保存する。
- ページ非表示／pagehideで共通の休止状態へ入り、visibilitychange／pageshowは一度だけ復帰処理を行う。1分以上のforeground停止も同じオフライン計算へ回す。
- 保存データの書出しは、利用者がボタンを押した場合だけJSONとしてダウンロードする。自動ダウンロードしない。JSONファイルの直接取込UIは未実装。接続先設定後はアカウントでクラウドへ手動保存・復元し、Windows版と進行を転送できる。自動同期と自動ログインは行わない。

## ストア

カタログの地面テーマは30秒の試着だけ利用できる。購入は常に拒否し、所有権を生成しない。Steamマーケットも利用不可。開発用sandbox購入をブラウザー版で有効にするURLパラメーターや設定は設けていない。プレビューを終了すると既定の外観へ戻る。

## 受入確認の範囲

スマホ版の製品受入には、実際の375px前後の縦画面、タブの横スクロール、3人の編成、帰還／再出発、手動育成と装備、再読込、背景復帰、保存容量不足、別タブ更新、書出し操作を確認する。ビルド成功だけで実機確認済みとは扱わない。

現時点ではWebアプリの入口であり、ストア配布済みのAndroid/iOSアプリやインストール可能なPWAではない。service workerによる素材キャッシュを実装していないため、オフラインでページを開き直せることは保証しない。ブラウザーのデータ消去・プライベートモード・OSによるサイトデータ削除にも注意が必要。公開HTTPS配信、インストール、通知、決済、プラットフォーム審査は別作業として検証する。
