# 06 仕上げと配布（M7）・その後

## 1. 全画面のアプリを使っているときに隠す

- 帯は常に最前面なので、全画面のゲームや動画、プレゼンの上に重なってしまう。M7で自動的に隠す。
- M1の時点で、帯は `setAlwaysOnTop(true, 'screen-saver')`（最前面の中でも高い段階）になっている。全画面のアプリの上にも出るため、この機能はM7より前に必要になる可能性がある。困った場合は、M7を待たずにトレイの「帯を隠す」で対処し、HANDOFFに記録する。
- 判定：`koffi`（FFI。ネイティブのビルドが不要）で `shell32.dll` の `SHQueryUserNotificationState` を2秒ごとに呼ぶ。`QUNS_BUSY`・`QUNS_RUNNING_D3D_FULL_SCREEN`・`QUNS_PRESENTATION_MODE` のとき帯を隠す。
- 補助の判定：前面のウィンドウ（`GetForegroundWindow` → `GetWindowRect`）が、帯のあるモニター全体を覆っているとき。デスクトップ（`Progman`／`WorkerW`）とタスクバー（`Shell_TrayWnd`）は除く。
- 隠れている間もシミュレーションは進める（一時停止はしない）。設定でオフにできる。
- koffiが読み込めない場合は機能を切り、ログに残す（ゲームは止めない）。

## 2. ログオン時の自動起動

- `app.setLoginItemSettings({ openAtLogin, args: ['--startup'] })`。配布用exeのときだけ設定に出す（開発中は出さない）。
- `--startup` で起動した場合は、パネルを開かず帯だけを出す。

## 3. 配布

- `electron-builder` の `portable`（インストール不要の1つのexe）を最初の形にする。インストーラー（nsis）は必要になってから。
- `pnpm dist` で `release/` に出力する（`.gitignore` に追加）。
- アイコン：トレイのドット絵を元に、256×256の `.ico` を `tools/` のスクリプトで作る（ドット絵を整数倍に拡大）。
- コード署名はしない。初回起動時にWindowsのSmartScreenの警告が出ることを、READMEに書く。
- 版の番号：`package.json` の `version` を、マイルストーンの完了ごとに `0.<M>.0` へ上げる。
- 配布物の確認は、`release/` のexeをプロジェクトの外の空のフォルダにコピーして起動する（開発用のセーブを使わないこと、利用者用のセーブの場所に作られることを確かめる）。確認後、コピーしたexeは削除する。

## 4. ログ

- `paths.logs` に `main.log` を書く（起動・終了・セーブの失敗・例外・koffiの状態）。1MBを超えたら `main.1.log` に移して新しく書く（2つまで）。
- 帯とパネルの例外は、IPCでmainに送ってログに書く。

## 5. その後の追加案（未決定。実装する前に相談する）

- **新しいジョブ**：巫女（結界・回復）、ギャル（味方の攻撃速度UP）、社畜（HPが減るほど強い。表現に注意）、配信者（視聴者数が溜まると強化）、力士（前衛の盾）。5人の枠は変えずに、控えと入れ替える仕組みにする。
- **転生**：エリア3のボスを倒すと解放。Lv・装備・ステージを戻す代わりに、永続の倍率（「徳」）を得る。
- **伝説の装備の固有効果**：例「村正：会心のたびにATK+5%（10回まで）」「全通チケット：オタクの奥義のゲージ+50%」。
- **時間帯**：PCの時刻が夜（22〜5時）のとき、妖怪のドロップ率が上がる。キー入力や作業の内容は読まない（プライバシーのため、この種の仕組みは作らない）。
- **エリア4・5**：ネオン街、終電の高架下（DESIGN.md §8.2）。
- **効果音**：ミュートが基本のまま、オンのときだけ鳴らす。入手先とライセンスが決まってから。

## 6. 受入条件（M7）

- 全画面の動画（ブラウザーの全画面）とプレゼンで帯が隠れ、終わると戻ることを実画面で確認。
- 配布用exeを、プロジェクトの外のフォルダから起動して、M0〜M6の実画面の確認項目を一通り行う。
- 自動起動をオン → 再ログオンで帯が出る（パネルは開かない）→ オフに戻す、を確認。
- 確認の後、`release/` 以外に残った作業用のコピーや中間物を削除し、空き容量と残ったプロセスを確認して記録する（AGENTS.mdの後片付け）。
