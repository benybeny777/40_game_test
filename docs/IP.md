# キャラクターIP化の準備

更新：2026-10-29。これは制作・管理の運用案。著作権・商標の取得済み、他者の権利を侵害しないこと、独占利用できることを断定する資料ではない。外部申請・登録・契約は実施していない。

## 識別子と設定の正本

`src/shared/characters.ts` が、安定したキャラクターIDとジョブ・外観の対応を管理する。ジョブは戦闘能力、キャラクターIDは人物、外観キーは描画素材を指す。同じジョブの別人には別IDを割り当て、衣装差分では元の人物IDを保持する。改名時もIDを変更しない。現17人の仮名・性格・口調・関係・台詞は [CHARACTERS.md](CHARACTERS.md) とレジストリを参照し、まだゲーム表示や商用の公式名には採用しない。

## 原本と制作経緯を記録する

現行の絵はAIを利用して制作している。ツールの生成原本、ゲームで使う最終PNG、生成指示、参照画像の役割、編集の履歴、人が採用・修正した内容を区別する。元絵の所在だけで監修済みとは扱わない。

| 記録項目 | 内容 |
|---|---|
| asset ID／character ID | 対象人物・衣装・表情・アニメの対応 |
| 生成時刻・ツール | 実際に使用した仕組みと実行記録。モデル名が不明なら推測しない |
| 生成原本 | 実在する保存先・元ファイル名・SHA-256。ツール側の原本とプロジェクトの最終素材を区別 |
| 指示と参照 | 指示全文、参照元の権利・利用条件、編集対象か画風参考か |
| 編集履歴 | メイド／シスターの区別、農民の体形、老人の汚れと箱一つなど、指示と採否を時系列で記録 |
| 人の寄与 | 誰が輪郭・色・表情・台詞・コマをどう修正したか。AIに再生成させた指示と手修正は別に書く |
| 最終監修 | 表示倍率・並び・動作確認、取り違え、切り抜き、既存人物への過度な類似を人が確認した日付と担当 |
| 採用状態 | 作業中／ゲーム採用／商用最終監修待ち。未確認を確認済みに変えない |

既存の生成指示記録は `assets/sprites/art/PROMPTS.md`、素材の出典は `docs/CREDITS.md`。画風変更前の指示と現行素材を混同せず、更新分の全文を追記する。レジストリの `humanReview: pending` は商用の最終監修がまだ記録されていないことを示し、現場で画面確認をした事実まで否定するものではない。

## 独自の人物として育てる

制作会話で使った既存作品・芸能人の名前は、販売上の公式キャラ名、広告文、検索向けのタグ、商品説明へ転用しない。殿は独自の顔・衣装・台詞へ、ガリ勉は独自の丸眼鏡の人物へ整理する。農民の竹槍など一般的な要素も、既存作品のスプライト・配色配置・シルエットをそのまま写す根拠にはしない。

キャラクターを立たせる要素は、単なる服装だけでなく、口調・価値観・得意不得意・他人への接し方・関係の変化まで揃える。既存作品のキャラの名前だけを変える作り方は採らない。将来の外部絵師・声優・ライターとの作業では、納品物、利用範囲、改変、二次利用、クレジットなどを契約で整理し、実際に確認していない利用許諾を取得済みと書かない。

## 法的な扱いの根拠と未確認事項

文化庁はAIと著作権に関する考え方や、当事者向けのチェックリスト・ガイダンスを公開している。個別の成果物について本プロジェクトが一律に権利を保証できる、という意味ではない。AI生成という理由だけで独占権や非侵害を断定せず、人の創作的な関与と制作経緯を記録する。[文化庁：AIと著作権について](https://www.bunka.go.jp/seisaku/chosakuken/aiandcopyright.html)

名称の商標調査・登録は未実施。仮名と製品名を固める際は、対象の商品・役務と同一・類似名称を調べ、必要に応じて専門家へ相談する。INPITは出願前の先行商標調査とJ-PlatPatの利用を案内している。[INPIT：商標出願前に注意すること](https://faq.inpit.go.jp/FAQ/2024/03/000288.html)、[J-PlatPat 商標検索](https://www.j-platpat.inpit.go.jp/t0100)

この準備は、ローカルでのゲーム実装・不具合修正・プレイ検証を止めるための承認ゲートにしない。未確認事項を残したまま「商用の権利確認が完了した」と宣伝しないことと、ゲーム制作を継続することを両立させる。
